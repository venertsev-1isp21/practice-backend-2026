# Booking API

**Система бронирования переговорных комнат** на Laravel и MySQL.


## Описание проекта

Проект реализует API для управления:

* Пользователями и ролями
* Переговорными комнатами
* Характеристиками комнат
* Бронированиями с различными статусами

Поддерживается система ролей и прав доступа. Реализована авторизация через **Laravel Sanctum**.


## Структура репозитория

```
src/
├─ app/
│  ├─ Models/           # Eloquent модели
│  ├─ Http/
│  │  ├─ Controllers/   # Контроллеры для API
│  │  └─ Middleware/    # Авторизация и роли
├─ database/
│  ├─ migrations/       # Миграции БД
│  └─ seeders/          # Заполнение тестовыми данными
├─ routes/
│  └─ api.php           # Маршруты API
└─ .env.example         # Настройки окружения
```


## Роли и права

| Действие                         | Admin | Manager |       User      |
| -------------------------------- | :---: | :-----: | :-------------: |
| Просмотр всех комнат             |   ✅   |    ✅    |        ✅        |
| Создание / редактирование комнат |   ✅   |    ✅    |        ❌        |
| Удаление комнат                  |   ✅   |    ❌    |        ❌        |
| Просмотр всех бронирований       |   ✅   |    ✅    |        ❌        |
| Просмотр своих бронирований      |   ✅   |    ✅    |        ✅        |
| Создание бронирования            |   ✅   |    ✅    |        ✅        |
| Изменение / отмена бронирования  |   ✅   |    ✅    | ✅ (только свои) |
| Управление пользователями        |   ✅   |    ❌    |        ❌        |
| Управление ролями                |   ✅   |    ❌    |        ❌        |

## Авторизация (API Token / Sanctum)

Все защищенные маршруты требуют **Bearer Token** в заголовке:

```
Authorization: Bearer <token>
```

### Endpoints

| Метод | URL             | Описание                     |
| ----- | --------------- | ---------------------------- |
| POST  | `/api/register` | Регистрация пользователя     |
| POST  | `/api/login`    | Логин, получение токена      |
| POST  | `/api/logout`   | Логаут, удаление токена      |
| GET   | `/api/me`       | Данные текущего пользователя |

## Фильтрация, сортировка и пагинация

### Примеры

**Bookings с фильтром и сортировкой**

```
GET /api/bookings?page=1&per_page=10&sort=start_time&order=asc&status=confirmed
```

**Поиск свободных ресурсов**

```
GET /api/resources/free?start=2026-03-20 10:00&end=2026-03-20 12:00
```

**Сортировка опросов**

```
GET /api/surveys?status=active&sort=created_at&order=desc
```

## Настройка и запуск проекта

1. Склонировать репозиторий:

```bash
git clone <repo-url>
cd booking-api
```

2. Установить зависимости:

```bash
composer install
```

3. Создать `.env` из примера и настроить БД:

```bash
cp .env.example .env
```

4. Сгенерировать ключ приложения:

```bash
php artisan key:generate
```

5. Применить миграции и заполнить тестовыми данными:

```bash
php artisan migrate --seed
```

6. Запустить сервер разработки:

```bash
php artisan serve
```
